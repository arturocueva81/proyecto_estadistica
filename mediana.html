Mediana

Definición

La mediana es el valor que se encuentra exactamente en el centro de un conjunto de datos cuando estos están ordenados de menor a mayor.

Si la cantidad de datos es impar, la mediana es el valor central. Si es par, la mediana es el promedio de los dos valores centrales.

Ejemplo con cantidad impar

Datos: 3, 7, 1, 9, 5

Paso 1: Ordenamos de menor a mayor: 1, 3, 5, 7, 9

Paso 2: El valor del centro es 5

La mediana es 5.

Ejemplo con cantidad par

Datos: 2, 4, 6, 8

Paso 1: Ya están ordenados: 2, 4, 6, 8

Paso 2: Los dos valores centrales son 4 y 6

Paso 3: Promediamos: (4 + 6) / 2 = 5

La mediana es 5.

¿Cómo se calcula en JavaScript?

// --- Calcular la MEDIANA ---

let listaCalificaciones = [3, 7, 1, 9, 5];

// Se ordena el arreglo de menor a mayor antes de buscar el centro
listaCalificaciones.sort(function(valorA, valorB) {
    return valorA - valorB;
});

let posicionCentral = Math.floor(listaCalificaciones.length / 2);
let valorMediana = 0;

// Si la cantidad de datos es par, se promedian los dos valores centrales
if (listaCalificaciones.length % 2 === 0) {
    valorMediana = (listaCalificaciones[posicionCentral - 1] +
                    listaCalificaciones[posicionCentral]) / 2;
} else {
    valorMediana = listaCalificaciones[posicionCentral];
}

console.log("La mediana es: " + valorMediana);
