Moda

Definición

La moda es el valor que más se repite dentro de un conjunto de datos. Un conjunto puede tener una moda (unimodal), dos modas (bimodal), varias modas (multimodal) o ninguna moda si todos los valores aparecen la misma cantidad de veces.

Ejemplo

Calificaciones de un grupo: 8, 7, 9, 8, 10, 8, 7

Contamos las repeticiones:

  • 7 aparece 2 veces
  • 8 aparece 3 veces
  • 9 aparece 1 vez
  • 10 aparece 1 vez

El valor que más se repite es el 8, por lo tanto la moda es 8.

¿Cómo se calcula en JavaScript?

// --- Calcular la MODA en JavaScript ---

let listaCalificaciones = [8, 7, 9, 8, 10, 8, 7];
let listaConteos = [];

// BUCLE EXTERNO: recorre cada calificación del arreglo
for (let indiceCalificacion = 0; indiceCalificacion < listaCalificaciones.length; indiceCalificacion++) {
    let yaExiste = false;

    // BUCLE INTERNO: busca si la calificación ya fue registrada
    for (let indiceConteo = 0; indiceConteo < listaConteos.length; indiceConteo++) {
        if (listaConteos[indiceConteo].valor === listaCalificaciones[indiceCalificacion]) {
            listaConteos[indiceConteo].conteo = listaConteos[indiceConteo].conteo + 1;
            yaExiste = true;
        }
    }

    // Si no existe, se agrega como nuevo registro con conteo 1
    if (yaExiste === false) {
        listaConteos.push({ valor: listaCalificaciones[indiceCalificacion], conteo: 1 });
    }
}

let valorModa = listaConteos[0].valor;
let conteoMaximo = listaConteos[0].conteo;

// Se busca el valor con mayor frecuencia
for (let indiceConteo = 1; indiceConteo < listaConteos.length; indiceConteo++) {
    if (listaConteos[indiceConteo].conteo > conteoMaximo) {
        conteoMaximo = listaConteos[indiceConteo].conteo;
        valorModa = listaConteos[indiceConteo].valor;
    }
}

console.log("La moda es: " + valorModa);
