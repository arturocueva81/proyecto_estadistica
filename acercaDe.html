Acerca de este Proyecto

Descripción

Este sitio web es el resultado del Proyecto de Matemática 1, desarrollado como aplicación práctica de la estadística descriptiva mediante tecnologías web: HTML, CSS y JavaScript puro.

El proyecto implementa desde cero, sin librerías externas de cálculo, las principales medidas estadísticas: media, mediana, moda, mínimo, máximo, rango, varianza y desviación estándar. Cada medida cuenta con explicación teórica, ejemplo manual, código JavaScript comentado, ejemplo interactivo y visualización con Chart.js.

Tecnologías utilizadas

  • HTML5: estructura semántica del sitio
  • CSS3: estilos y layout de dos columnas
  • JavaScript (ES6): lógica estadística y manipulación del DOM
  • Chart.js: visualización de gráficos interactivos
  • Font Awesome: iconografía

Dataset

El ejercicio práctico utiliza una muestra de 200 registros del dataset Social Media Usage Dataset publicado en Kaggle, que registra el comportamiento diario de usuarios en redes sociales en USA (2024).
