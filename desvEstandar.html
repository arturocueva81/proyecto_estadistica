Desviación Estándar

Definición

La desviación estándar es la raíz cuadrada de la varianza. Nos indica, en las mismas unidades de los datos originales, qué tanto se desvían los valores respecto a la media.

Fórmula: Desviación Estándar = √Varianza

Una desviación estándar baja indica que los datos están agrupados cerca del promedio. Una desviación alta indica que están muy dispersos.

Ejemplo

Usando los datos del ejemplo anterior: 4, 8, 6, 2, 10

Ya calculamos que la varianza es 8.

Desviación estándar = √8 = 2.83 (aproximadamente)

Esto significa que, en promedio, los datos se desvían 2.83 unidades respecto a la media de 6.

¿Cómo se calcula en JavaScript?

// --- Calcular la DESVIACIÓN ESTÁNDAR en JavaScript ---

let listaDatos = [4, 8, 6, 2, 10];
let sumaDatos = 0;

for (let indiceDato = 0; indiceDato < listaDatos.length; indiceDato++) {
    sumaDatos = sumaDatos + listaDatos[indiceDato];
}

let valorMedia = sumaDatos / listaDatos.length;
let sumaCuadradosDiferencias = 0;

for (let indiceDato = 0; indiceDato < listaDatos.length; indiceDato++) {
    let valorDiferencia = listaDatos[indiceDato] - valorMedia;
    sumaCuadradosDiferencias = sumaCuadradosDiferencias + (valorDiferencia * valorDiferencia);
}

let valorVarianza = sumaCuadradosDiferencias / listaDatos.length;
let valorDesviacion = Math.sqrt(valorVarianza);

console.log("La desviación estándar es: " + valorDesviacion.toFixed(2));
