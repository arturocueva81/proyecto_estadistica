¿Qué es la Estadística?

Definición

La estadística es una rama de las matemáticas que se encarga de recopilar, organizar, analizar e interpretar datos numéricos. Su objetivo es obtener conclusiones útiles a partir de la información recopilada.

Existen dos tipos principales:

  • Estadística descriptiva: resume y describe las características de un conjunto de datos.
  • Estadística inferencial: permite hacer predicciones o generalizaciones a partir de una muestra.

Ejemplo

Un profesor registra las calificaciones de 5 estudiantes: 7, 8, 6, 9, 10.

Con estadística descriptiva podemos calcular el promedio, la mediana, el valor más alto y el más bajo de esas calificaciones para entender mejor el rendimiento del grupo.

Media (Promedio)

Definición

La media aritmética, comúnmente llamada promedio, es el resultado de sumar todos los valores de un conjunto de datos y dividir esa suma entre la cantidad total de valores.

Fórmula: Media = Suma de todos los valores / Cantidad de valores

Ejemplo

Las edades de 5 personas son: 20, 25, 30, 22, 28

Paso 1: Sumamos todos los valores: 20 + 25 + 30 + 22 + 28 = 125

Paso 2: Dividimos entre la cantidad de valores (5): 125 / 5 = 25

La media de las edades es 25 años.

¿Cómo se calcula en JavaScript?

// --- Calcular la MEDIA (Promedio) en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [20, 25, 30, 22, 28];

// Paso 2: Crear una variable para acumular la suma
// Empieza en 0 porque aun no hemos sumado nada
var suma = 0;

// Paso 3: Recorrer el array con un ciclo for
// El for va desde la posicion 0 hasta la ultima posicion
// datos.length nos dice cuantos elementos tiene el array
for (var i = 0; i < datos.length; i++) {
    // En cada vuelta, sumamos el valor actual al acumulador
    suma = suma + datos[i];
}

// Paso 4: Dividir la suma entre la cantidad de datos
var media = suma / datos.length;

// Paso 5: Mostrar el resultado en la consola del navegador
console.log("La media es: " + media);
// Resultado: La media es: 25

Mediana

Definición

La mediana es el valor que se encuentra exactamente en el centro de un conjunto de datos cuando estos están ordenados de menor a mayor.

Si la cantidad de datos es impar, la mediana es el valor central. Si es par, la mediana es el promedio de los dos valores centrales.

Ejemplo con cantidad impar

Datos: 3, 7, 1, 9, 5

Paso 1: Ordenamos de menor a mayor: 1, 3, 5, 7, 9

Paso 2: El valor del centro es 5

La mediana es 5.

Ejemplo con cantidad par

Datos: 2, 4, 6, 8

Paso 1: Ya están ordenados: 2, 4, 6, 8

Paso 2: Los dos valores centrales son 4 y 6

Paso 3: Promediamos: (4 + 6) / 2 = 5

La mediana es 5.

¿Cómo se calcula en JavaScript?

// --- Calcular la MEDIANA en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [3, 7, 1, 9, 5];

// Paso 2: Ordenar el array de menor a mayor
// El metodo sort() ordena, pero necesita una funcion
// que le diga como comparar numeros.
// Si (a - b) es negativo, "a" va primero.
// Si (a - b) es positivo, "b" va primero.
datos.sort(function(a, b) {
    return a - b;
});
// Ahora datos = [1, 3, 5, 7, 9]

// Paso 3: Encontrar la posicion del centro
// Math.floor() redondea hacia abajo (quita decimales)
var centro = Math.floor(datos.length / 2);

// Paso 4: Verificar si la cantidad de datos es par o impar
// El operador % (modulo) nos da el residuo de la division
// Si el residuo de dividir entre 2 es 0, el numero es par
var mediana;

if (datos.length % 2 === 0) {
    // Si es PAR: promediamos los dos valores centrales
    mediana = (datos[centro - 1] + datos[centro]) / 2;
} else {
    // Si es IMPAR: tomamos el valor del centro directamente
    mediana = datos[centro];
}

console.log("La mediana es: " + mediana);
// Resultado: La mediana es: 5

Moda

Definición

La moda es el valor que más se repite dentro de un conjunto de datos. Un conjunto puede tener una moda (unimodal), dos modas (bimodal), varias modas (multimodal) o ninguna moda si todos los valores aparecen la misma cantidad de veces.

Ejemplo

Calificaciones de un grupo: 8, 7, 9, 8, 10, 8, 7

Contamos las repeticiones:

  • 7 aparece 2 veces
  • 8 aparece 3 veces
  • 9 aparece 1 vez
  • 10 aparece 1 vez

El valor que más se repite es el 8, por lo tanto la moda es 8.

¿Cómo se calcula en JavaScript?

// --- Calcular la MODA en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [8, 7, 9, 8, 10, 8, 7];

// Paso 2: Crear un array de objetos para contar repeticiones
// Cada objeto tendra: { valor: numero, conteo: veces }
var conteos = [];

// Paso 3: Recorrer cada dato y contar cuantas veces aparece
for (var i = 0; i < datos.length; i++) {

    // Buscamos si el valor ya existe en nuestro array de conteos
    var encontrado = false;

    for (var j = 0; j < conteos.length; j++) {
        // Si ya existe, aumentamos su conteo en 1
        if (conteos[j].valor === datos[i]) {
            conteos[j].conteo = conteos[j].conteo + 1;
            encontrado = true;
        }
    }

    // Si no lo encontramos, lo agregamos con conteo = 1
    if (encontrado === false) {
        conteos.push({ valor: datos[i], conteo: 1 });
    }
}

// Paso 4: Buscar cual tiene el conteo mas alto
var moda = conteos[0].valor;
var maxConteo = conteos[0].conteo;

for (var k = 1; k < conteos.length; k++) {
    if (conteos[k].conteo > maxConteo) {
        maxConteo = conteos[k].conteo;
        moda = conteos[k].valor;
    }
}

console.log("La moda es: " + moda);
// Resultado: La moda es: 8

Valor Mínimo y Valor Máximo

Definición

El valor mínimo es el número más pequeño dentro de un conjunto de datos.

El valor máximo es el número más grande dentro de un conjunto de datos.

Estos dos valores nos permiten conocer los extremos del conjunto y son la base para calcular el rango.

Ejemplo

Temperaturas registradas durante una semana: 18, 22, 15, 28, 20, 25, 17

Ordenamos de menor a mayor: 15, 17, 18, 20, 22, 25, 28

Valor mínimo: 15°C

Valor máximo: 28°C

¿Cómo se calcula en JavaScript?

// --- Calcular el MINIMO y MAXIMO en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [18, 22, 15, 28, 20, 25, 17];

// Paso 2: Asumimos que el primer valor es el minimo y el maximo
// Despues lo compararemos con los demas valores
var minimo = datos[0];
var maximo = datos[0];

// Paso 3: Recorrer el array desde la posicion 1
// (la posicion 0 ya la usamos arriba)
for (var i = 1; i < datos.length; i++) {

    // Si el valor actual es menor que el minimo guardado,
    // actualizamos el minimo
    if (datos[i] < minimo) {
        minimo = datos[i];
    }

    // Si el valor actual es mayor que el maximo guardado,
    // actualizamos el maximo
    if (datos[i] > maximo) {
        maximo = datos[i];
    }
}

console.log("Valor minimo: " + minimo);
console.log("Valor maximo: " + maximo);
// Resultado: Valor minimo: 15
// Resultado: Valor maximo: 28

Rango

Definición

El rango es la diferencia entre el valor máximo y el valor mínimo de un conjunto de datos. Nos indica qué tan dispersos o separados están los datos.

Fórmula: Rango = Valor Máximo - Valor Mínimo

Ejemplo

Temperaturas de la semana: 15, 17, 18, 20, 22, 25, 28

Valor máximo: 28

Valor mínimo: 15

Rango = 28 - 15 = 13°C

Esto significa que la temperatura varió 13 grados durante la semana.

¿Cómo se calcula en JavaScript?

// --- Calcular el RANGO en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [15, 17, 18, 20, 22, 25, 28];

// Paso 2: Encontrar el minimo y el maximo
// Reutilizamos la misma logica de la seccion anterior
var minimo = datos[0];
var maximo = datos[0];

for (var i = 1; i < datos.length; i++) {
    if (datos[i] < minimo) {
        minimo = datos[i];
    }
    if (datos[i] > maximo) {
        maximo = datos[i];
    }
}

// Paso 3: El rango es la resta del maximo menos el minimo
var rango = maximo - minimo;

console.log("El rango es: " + rango);
// Resultado: El rango es: 13

Varianza

Definición

La varianza mide qué tan lejos están los datos respecto a la media (promedio). Si la varianza es alta, los datos están muy dispersos. Si es baja, los datos están cercanos al promedio.

Pasos para calcularla:

  1. Calcular la media del conjunto.
  2. Restar la media a cada valor (obtener las diferencias).
  3. Elevar cada diferencia al cuadrado.
  4. Sumar todas las diferencias al cuadrado.
  5. Dividir entre la cantidad total de datos.

Ejemplo

Datos: 4, 8, 6, 2, 10

Paso 1 - Media: (4 + 8 + 6 + 2 + 10) / 5 = 6

Paso 2 - Diferencias: (4-6), (8-6), (6-6), (2-6), (10-6) = -2, 2, 0, -4, 4

Paso 3 - Cuadrados: 4, 4, 0, 16, 16

Paso 4 - Suma de cuadrados: 4 + 4 + 0 + 16 + 16 = 40

Paso 5 - Varianza: 40 / 5 = 8

La varianza es 8.

¿Cómo se calcula en JavaScript?

// --- Calcular la VARIANZA en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [4, 8, 6, 2, 10];

// Paso 2: Calcular la media (promedio)
// Primero sumamos todos los valores
var suma = 0;
for (var i = 0; i < datos.length; i++) {
    suma = suma + datos[i];
}
var media = suma / datos.length;
// media = 30 / 5 = 6

// Paso 3: Calcular la suma de las diferencias al cuadrado
// Para cada dato: restamos la media, y elevamos al cuadrado
var sumaCuadrados = 0;

for (var i = 0; i < datos.length; i++) {
    // Calculamos la diferencia entre el dato y la media
    var diferencia = datos[i] - media;

    // Elevamos al cuadrado multiplicando por si mismo
    // Esto elimina los numeros negativos
    var cuadrado = diferencia * diferencia;

    // Acumulamos en la suma total
    sumaCuadrados = sumaCuadrados + cuadrado;
}

// Paso 4: Dividir la suma de cuadrados entre la cantidad de datos
var varianza = sumaCuadrados / datos.length;

console.log("La varianza es: " + varianza);
// Resultado: La varianza es: 8

Desviación Estándar

Definición

La desviación estándar es la raíz cuadrada de la varianza. Nos indica, en las mismas unidades de los datos originales, qué tanto se desvían los valores respecto a la media.

Fórmula: Desviación Estándar = √Varianza

Una desviación estándar baja indica que los datos están agrupados cerca del promedio. Una desviación alta indica que están muy dispersos.

Ejemplo

Usando los datos del ejemplo anterior: 4, 8, 6, 2, 10

Ya calculamos que la varianza es 8.

Desviación estándar = √8 = 2.83 (aproximadamente)

Esto significa que, en promedio, los datos se desvían 2.83 unidades respecto a la media de 6.

¿Cómo se calcula en JavaScript?

// --- Calcular la DESVIACION ESTANDAR en JavaScript ---

// Paso 1: Crear un array con los datos
var datos = [4, 8, 6, 2, 10];

// Paso 2: Calcular la media (promedio)
var suma = 0;
for (var i = 0; i < datos.length; i++) {
    suma = suma + datos[i];
}
var media = suma / datos.length;

// Paso 3: Calcular la varianza
// (suma de diferencias al cuadrado / cantidad de datos)
var sumaCuadrados = 0;
for (var i = 0; i < datos.length; i++) {
    var diferencia = datos[i] - media;
    sumaCuadrados = sumaCuadrados + (diferencia * diferencia);
}
var varianza = sumaCuadrados / datos.length;
// varianza = 40 / 5 = 8

// Paso 4: La desviacion estandar es la raiz cuadrada de la varianza
// Math.sqrt() es una funcion de JavaScript que calcula
// la raiz cuadrada de un numero
var desviacion = Math.sqrt(varianza);

// Paso 5: Redondear a 2 decimales con toFixed(2)
// toFixed(2) convierte el numero a texto con 2 decimales
console.log("La desviacion estandar es: " + desviacion.toFixed(2));
// Resultado: La desviacion estandar es: 2.83
