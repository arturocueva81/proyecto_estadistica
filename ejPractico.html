Ejercicio Práctico

Contexto del dataset

Este ejercicio utiliza una muestra de 200 registros tomados aleatoriamente de un dataset original de 1.000 usuarios de redes sociales, publicado en Kaggle.

Cada registro representa el comportamiento diario de un usuario en una red social específica en USA en el año 2024. Las variables registradas son:

  • App: red social utilizada (Instagram, TikTok, Facebook, etc.)
  • Daily_Minutes_Spent: minutos diarios que el usuario pasa en la app
  • Posts_Per_Day: publicaciones realizadas por día
  • Likes_Per_Day: likes dados por día
  • Follows_Per_Day: cuentas seguidas por día

Vista previa del dataset

Los primeros 10 registros del dataset para entender la estructura de los datos que se van a analizar:

# User ID App Min / Día Posts / Día Likes / Día Follows / Día

El objetivo de este ejercicio es calcular métricas estadísticas para comparar el comportamiento de los usuarios en cada red social.

Selecciona el cálculo estadístico

Elige una opción para visualizar únicamente el ejercicio correspondiente.

📘 Media — Minutos diarios por App

JavaScript recorre los 200 registros, los agrupa por App y calcula la media de Daily_Minutes_Spent para cada red social.

📊 Gráfico comparativo

Gráfico de barras con la media de minutos diarios por red social.

📗 Mediana — Minutos diarios

JavaScript ordena los 200 valores de Daily_Minutes_Spent de menor a mayor y encuentra el valor central del dataset completo.

📊 Gráfico de distribución

Valores ordenados con la línea de mediana como referencia visual.

📙 Moda — App más frecuente

JavaScript cuenta cuántas veces aparece cada App en los 200 registros y determina cuál es la red social más representada en el dataset.

📊 Gráfico de frecuencias

La barra más alta representa la App que más se repite (moda).

📕 Mínimo y Máximo — Minutos diarios

JavaScript recorre los 200 registros y encuentra el valor más bajo y el más alto de Daily_Minutes_Spent en todo el dataset.

📊 Gráfico de extremos

La barra roja es el mínimo y la barra verde es el máximo.

📒 Rango — Amplitud de minutos diarios

JavaScript calcula la diferencia entre el valor máximo y el mínimo de Daily_Minutes_Spent para conocer la amplitud total del dataset.

📊 Gráfico de amplitud

Visualiza la distancia entre el valor mínimo y el máximo del dataset.

📓 Varianza — Dispersión de minutos diarios

JavaScript calcula qué tan dispersos están los 200 valores de Daily_Minutes_Spent respecto a la media del dataset completo.

📊 Gráfico de desviaciones

Compara cada valor con la media y visualiza la dispersión del dataset.

📔 Desviación Estándar — Minutos diarios

JavaScript calcula la raíz cuadrada de la varianza de Daily_Minutes_Spent para obtener la dispersión en las mismas unidades que los datos originales.

📊 Gráfico de dispersión

Muestra visualmente qué tan alejados están los datos respecto al promedio.
