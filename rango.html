Rango

Definición

El rango es la diferencia entre el valor máximo y el valor mínimo de un conjunto de datos. Nos indica qué tan dispersos o separados están los datos.

Fórmula: Rango = Valor Máximo - Valor Mínimo

Ejemplo

Temperaturas de la semana: 15, 17, 18, 20, 22, 25, 28

Valor máximo: 28

Valor mínimo: 15

Rango = 28 - 15 = 13°C

Esto significa que la temperatura varió 13 grados durante la semana.

¿Cómo se calcula en JavaScript?

// --- Calcular el RANGO en JavaScript ---

let listaTemperaturas = [15, 17, 18, 20, 22, 25, 28];
let valorMinimo = listaTemperaturas[0];
let valorMaximo = listaTemperaturas[0];

for (let indiceTemperatura = 1; indiceTemperatura < listaTemperaturas.length; indiceTemperatura++) {
    if (listaTemperaturas[indiceTemperatura] < valorMinimo) {
        valorMinimo = listaTemperaturas[indiceTemperatura];
    }
    if (listaTemperaturas[indiceTemperatura] > valorMaximo) {
        valorMaximo = listaTemperaturas[indiceTemperatura];
    }
}

let valorRango = valorMaximo - valorMinimo;
console.log("El rango es: " + valorRango);
