Valor Mínimo y Valor Máximo

Definición

El valor mínimo es el número más pequeño dentro de un conjunto de datos.

El valor máximo es el número más grande dentro de un conjunto de datos.

Estos dos valores nos permiten conocer los extremos del conjunto y son la base para calcular el rango.

Ejemplo

Temperaturas registradas durante una semana: 18, 22, 15, 28, 20, 25, 17

Ordenamos de menor a mayor: 15, 17, 18, 20, 22, 25, 28

Valor mínimo: 15°C

Valor máximo: 28°C

¿Cómo se calcula en JavaScript?

// --- Calcular el MÍNIMO y MÁXIMO en JavaScript ---

let listaTemperaturas = [18, 22, 15, 28, 20, 25, 17];
let valorMinimo = listaTemperaturas[0];
let valorMaximo = listaTemperaturas[0];

// Se recorre desde el índice 1 porque el índice 0 ya fue asignado como referencia
for (let indiceTemperatura = 1; indiceTemperatura < listaTemperaturas.length; indiceTemperatura++) {
    if (listaTemperaturas[indiceTemperatura] < valorMinimo) {
        valorMinimo = listaTemperaturas[indiceTemperatura];
    }
    if (listaTemperaturas[indiceTemperatura] > valorMaximo) {
        valorMaximo = listaTemperaturas[indiceTemperatura];
    }
}

console.log("Valor mínimo: " + valorMinimo);
console.log("Valor máximo: " + valorMaximo);
